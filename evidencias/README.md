# Carpeta de Evidencias — mundos-ia

En esta carpeta se encuentran registradas las evidencias solicitadas para la entrega del taller:

1. **`01-mundo-uno.log`**: Comando ejecutado, salida completa en consola, JSON, descripción generada y confirmación de la imagen del Mundo 1 (`Aerópolis`).
2. **`02-mundo-dos.log`**: Comando ejecutado, salida completa en consola, JSON, descripción generada y confirmación de la imagen del Mundo 2 (`Obsidiana`).
3. **`03-reutilizacion-cache.log`**: Demostración de la segunda ejecución del mismo comando, donde el sistema detecta los archivos existentes y ahorra cuota de las APIs.
4. **`04-errores-provocados.log`**: Tres errores provocados intencionalmente (clave inválida HTTP 401, modelo/ruta inexistente HTTP 404, y sin conexión / fallo de red `TypeError`) mostrando sus mensajes explicativos en español sin trazas técnicas ni filtración de credenciales.
5. **`05-npm-publish-dry-run.log`**: Auditoría de empaquetado con `npm publish --dry-run` con `.gitignore` activo y el resultado del experimento al renombrar temporalmente a `.gitignore.off`, explicando los riesgos de seguridad.
6. **`06-git-ls-files.log`**: Salida del comando `git ls-files` demostrando que `.env` no forma parte del árbol de control de versiones.
7. **Imágenes generadas de los dos mundos:**
   - [`mundo_cba86145.jpg`](./mundo_cba86145.jpg) — Representación visual de Aerópolis amenazada por tormenta eléctrica (155 KB).
   - [`mundo_a97b6924.jpg`](./mundo_a97b6924.jpg) — Representación visual de Obsidiana con magma cristalino y guardianes mecánicos (306 KB).
